`pixi add python` resolved conda-forge Python 3.15 on osx-arm64, which ships no libpython*.dylib, so any Mojo code touching std.python aborts at runtime with 'Failed to load libpython' (compiles fine). Pinning `python = ">=3.13,<3.14"` provides libpython3.13.dylib and the chat walk works. Mojo has no stdlib HTTP client, so utils/llm_chat.mojo uses Python urllib/json via interop, converting PythonObject to Mojo types inside the util so nodes and fakes never see Python.
